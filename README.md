## 🔑 Overview

This project simulates the responsibilities of a Cloud Security Analyst. It integrates IAM configuration, firewall rules, monitoring/logging, incident response planning, and risk assessment into a cohesive security solution. It also demonstrates automation with Python for log parsing and threat detection.

- **IAM Policies**: Least‑privilege role assignments

- **Monitoring & Logging**: Threat detection and audit trails

- **Risk Assessment**: Vulnerability identification and mitigation strategies  
- **Python Automation**: Log parser for suspicious activity detection
